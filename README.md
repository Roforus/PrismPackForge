# Prism Pack Forge

**Модовая сборка Minecraft — в готовый установщик для друзей.**

Prism Pack Forge — Windows-утилита для экспорта установленных сборок Minecraft в автономные EXE установщики. Она помогает переносить сборки между лаунчерами и распространять обновления: моды скачиваются из Modrinth и CurseForge, а конфиги и настройки передаются вместе со сборкой.

**[Скачать EXE для Windows](https://github.com/Roforus/PrismPackForge/releases/latest/download/PrismPackForge.exe)** · [Все релизы](https://github.com/Roforus/PrismPackForge/releases)

## Возможности

- Экспорт сборок из Prism/MultiMC и игровых папок других Java-лаунчеров.
- Автономные EXE без необходимости устанавливать Python.
- Установка и обновление сборок с поиском существующих установок.
- Подготовка нужной версии Minecraft и модлоадера для поддерживаемых лаунчеров.
- Проверка загруженных файлов и резервные копии заменяемых данных.
- Сохранение параметров последней выгрузки, светлая и тёмная темы.

JAR модов не встраиваются в установщик — используются ссылки на исходные файлы.

## Совместимость

Экспорт: **Prism Launcher, MultiMC**, а также игровые папки **CurseForge, Modrinth App и других лаунчеров** с ручным указанием версий.

Установка: **Prism Launcher, MultiMC, Minecraft Launcher, Legacy Launcher и TLauncher**. Поддерживаются **Fabric, Forge, NeoForge, Quilt и Vanilla** в пределах возможностей выбранного лаунчера.

## Запуск из исходников

Windows, Python **3.11+** с Tkinter:

```powershell
git clone https://github.com/Roforus/PrismPackForge.git
cd PrismPackForge
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\.venv\Scripts\python.exe -m packforge
```

Выберите сборку Prism, задайте постоянный ID, название, версию и папку результата, затем нажмите **«Экспортировать сборку»**. Передайте игрокам полученный `<id>-setup.exe`. Для установки нужен интернет. Сохраняйте ID при выпуске обновлений.

Если нет `options.txt`, сначала запустите игру в Prism, настройте и закройте её. Для файлов, отсутствующих на Modrinth, может потребоваться собственный CurseForge API-ключ. Неопознанные или недоступные для прямого скачивания файлы останавливают экспорт с отчётом.

## Сборка утилиты в EXE

```powershell
.\.venv\Scripts\python.exe scripts/build_app.py
```

Результат — `dist/PrismPackForge.exe`. Встроенный шаблон позволяет создавать установщики без внешнего Python/PyInstaller. Закройте предыдущий EXE перед пересборкой. Готовые бинарники и пользовательские сборки в Git не хранятся.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
