# Prism Pack Forge

Экспорт модовых сборок из **Prism Launcher** в автономные Windows EXE установщики для **Prism, Legacy Launcher и TLauncher**.

Установщик скачивает моды по ссылкам Modrinth/CurseForge. JAR файлов внутри него нет. Конфиги, скрипты и настройки игры передаются вместе со сборкой.

## Возможности

- Выбор экземпляра из списка сборок Prism, включая portable-каталоги.
- EXE экспортёра и установщики работают без установленного Python.
- Для Legacy/TLauncher автоматически устанавливаются точные версии Minecraft и Fabric, Forge, NeoForge или Quilt. В Prism создаётся экземпляр с нужными компонентами.
- Поиск установленной сборки и предложение обновления. При новой установке приоритет лаунчеров: Prism → Legacy → TLauncher.
- Проверка файлов по SHA-512, резервные копии и откат при ошибке применения изменений.
- `options.txt` включается всегда и обязательно применяется при первой установке. При обновлении настройки игрока сохраняются, пока он не выбрал замену.
- Последние параметры экспорта запоминаются отдельно для каждой сборки. API-ключ не сохраняется.

## Запуск из исходников

Windows, Python **3.11+** с Tkinter:

```powershell
git clone https://github.com/Roforus/PrismPackForge.git
cd PrismPackForge
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
.\.venv\Scripts\python.exe -m packforge
```

Выберите сборку Prism, задайте постоянный ID, название, версию и папку результата, затем нажмите **«Экспортировать сборку»**. Передайте игрокам полученный `<id>-setup.exe`. Для установки нужен интернет. Сохраняйте ID при выпуске обновлений.

Если нет `options.txt`, сначала запустите игру в Prism, настройте и закройте её. Для файлов, отсутствующих на Modrinth, может потребоваться собственный CurseForge API-ключ. Неопознанные или недоступные для прямого скачивания файлы останавливают экспорт с отчётом.

## Сборка утилиты в EXE

```powershell
.\.venv\Scripts\python.exe scripts/build_app.py
```

Результат — `dist/PrismPackForge.exe`. Встроенный шаблон позволяет создавать установщики без внешнего Python/PyInstaller. Закройте предыдущий EXE перед пересборкой. Готовые бинарники и пользовательские сборки в Git не хранятся.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проект не является официальным продуктом Mojang/Microsoft, Prism Launcher, Modrinth, CurseForge или других упомянутых проектов. EXE не подписаны цифровой подписью, поэтому Windows может предупреждать о неизвестном издателе.
