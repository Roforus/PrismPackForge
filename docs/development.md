| `packforge/appearance.py` | Светлая/тёмная тема и сохранение оформления |
| `packforge/export_ui.py` | Сгруппированные поля, выбор исходного лаунчера и настройки |

| `packforge/exporter.py` | Поиск файлов экземпляра, манифест и сборка установщика |
| `packforge/providers.py` | Поиск точных файлов Modrinth/CurseForge по хешам |
| `packforge/installer.py` | Подготовка файлов, обновление, резервное копирование и откат |
| `packforge/game_runtime.py` | Подготовка Minecraft, Java и модлоадера для Legacy/TLauncher |
| `packforge/discovery.py` | Поиск лаунчеров и установленных сборок |
| `packforge/installer_ui.py` | Интерфейс установщика и рекомендации |
| `packforge/network.py` | Проверяемый HTTPS с системным хранилищем сертификатов и certifi |
| `packforge/standalone.py` | Добавление архива сборки во встроенный шаблон EXE |
| `scripts/build_app.py` | Сборка шаблона установщика и автономного экспортёра |
| `tests/` | Модульные проверки без загрузки игры |

## Формат сборки

`*.pack.zip` содержит `manifest.json` формата 1 и каталог `overrides/` со встроенными конфигами, скриптами и `options.txt`. Манифест задаёт постоянный ID, название, версию сборки, компоненты Prism, список файлов, размеры и SHA-512. Для скачиваемых файлов указаны источник, URL и идентификаторы проекта/версии; для встроенных — путь в архиве.

ID определяет принадлежность установки. Журнал `.packforge/state.json` хранит версию и хеши управляемых файлов. Удалять устаревшие моды можно только по этому журналу; изменённый пользователем мод вызывает конфликт. Общие библиотеки и старые версии Minecraft автоматически не удаляются.

Установка сначала подготавливает файлы отдельно от действующей игры. Изменения применяются после подготовки, заменённые файлы сохраняются в резервной копии. Исключение во время применения запускает откат. Завершение процесса извне или отключение питания этим откатом не покрываются.

## Сборка и проверка

Установка окружения и команды приведены в [README](../README.md). PyInstaller нужен только разработчику при сборке утилиты из исходников. Шаблон и утилита собираются на Windows. После изменения кода установщика пересоберите и утилиту, и распространяемые EXE сборок: ранее выданные файлы не обновляются автоматически.

Автономный экспортёр добавляет архив в CArchive встроенного неподписанного шаблона PyInstaller 6. При смене основной версии PyInstaller обязательно проверьте совместимость `standalone.py` и запуск полученного установщика. Подпись, если она появится, должна выполняться после формирования окончательного EXE.

Основная проверка:

```powershell
python -m unittest discover -s tests -v
```

Дополнительная интеграционная проверка:

```powershell
python scripts/smoke_test.py --build
```

Она скачивает реальные мод, Minecraft, Java и Fabric, создаёт данные в `.verification/`, но не запускает игру. Нужны интернет и несколько гигабайт свободного места. Модульные тесты не заменяют проверку запуска сборки в лаунчерах.

Не коммитьте API-ключи, личные настройки, игровые JAR, архивы сборок, содержимое `.verification/`, `build/` и `dist/`. Настройки и индекс установок находятся в пользовательском LocalAppData, а не в репозитории.

## Коммиты

Используется [Conventional Commits](https://habr.com/ru/articles/867012/): `type(scope): краткое описание`. Область необязательна. Выбирайте тип по смыслу изменения, например:

```text
feat(export): add Prism instance selection
fix(network): use system certificate trust
docs: document installation and update behavior
test(installer): cover rollback after a runtime failure
build: update the standalone installer template
```

Для несовместимых изменений добавляйте пояснение `BREAKING CHANGE:` в тело коммита. Не объединяйте несвязанные изменения в один коммит.
