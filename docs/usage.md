# Prism Pack Forge

В версии 0.2 также доступны экспорт из MultiMC и произвольной игровой папки, установка в MultiMC и официальный Minecraft Launcher, переключатель темы. Актуальная матрица совместимости и особенности этих режимов приведены в [README](../README.md).

Пример экспорта папки из другого лаунчера:

```powershell
python -m packforge export "D:\CurseForge\Instances\MyPack" --minecraft 1.21.1 --loader NeoForge --loader-version 21.1.1 --id my-pack --name "Моя сборка" --version 1.0.0 --output "dist\my-pack.pack.zip" --exe "dist\my-pack-setup.exe"
python -m packforge install "dist\my-pack.pack.zip" --launcher minecraft --destination "$env:APPDATA\.minecraft"
python -m packforge install "dist\my-pack.pack.zip" --launcher multimc --destination "D:\MultiMC\instances\my-pack"
```

Python-утилита для экспорта экземпляра Prism Launcher в Windows EXE установщик модовой сборки. Интерфейс на русском, доступен CLI.

## Быстрый запуск

Готовую утилиту можно запустить двойным щелчком по `dist/PrismPackForge.exe`. Python и PyInstaller для неё не нужны: создание EXE сборок работает через встроенный шаблон установщика. Передавайте пользователю этот один файл.

Для запуска из исходников:

Windows, Python 3.11+ с Tkinter:

```powershell
python -m pip install -e ".[build]"
python -m packforge
```

Пересборка самой автономной утилиты из исходников: `python scripts/build_app.py`.

HTTPS использует системное хранилище сертификатов (в Windows — CryptoAPI) и встроенный набор публичных корневых сертификатов certifi. Проверка сертификата и имени сервера обязательна. При исправлениях сетевого кода необходимо пересобрать установщики сборок: ранее выданные EXE содержат прежний код.

Выберите сборку Prism в списке утилиты. Укажите постоянный ID сборки латиницей, название, версию и папку результата. ID должен оставаться одинаковым при выпуске обновлений. Для CLI путь к экземпляру можно открыть в Prism через ПКМ по сборке → «Папка экземпляра»; эта папка содержит `mmc-pack.json`.

В графическом интерфейсе сборку можно выбрать из списка экземпляров Prism: утилита читает стандартный и настроенный каталог `InstanceDir`. Кнопка «Указать папку Prism…» добавляет portable-лаунчер или дополнительный каталог экземпляров. «Обновить список» повторяет поиск. Одинаковые имена различаются по пути.

Название, постоянный ID, версия, папка результата и флажки экспорта сохраняются отдельно для каждой сборки при экспорте, переключении сборки и закрытии окна. Последний выбор восстанавливается при запуске. Настройки находятся в `%LOCALAPPDATA%/PrismPackForge/export-settings.json`; API-ключ в этот файл не записывается. Временные файлы и cookies для постоянных настроек не используются.

`options.txt` всегда включается в экспорт. Если файла нет, запустите игру в Prism, настройте её и закройте перед экспортом. При первой установке настройки сборки применяются обязательно, даже если в целевой папке уже есть настройки другой игры; заменённый файл сохраняется в резервной копии. При обновлении настройки игрока сохраняются, если он явно не выбрал их замену.

Результат: `my-pack.pack.zip` и `my-pack-setup.exe`. Игрокам достаточно передать EXE, Python им не нужен. Во время установки необходим интернет. EXE собирается на Windows через PyInstaller; он не подписан цифровой подписью.

## Что входит в сборку

- Моды из `mods`, включая отключённые файлы, со ссылками на точные версии Modrinth/CurseForge.
- `config`, `defaultconfigs`, `kubejs`, `scripts`, `resourcepacks`, `shaderpacks`, `global_packs`, `datapacks`.
- Версии Minecraft и загрузчика из `mmc-pack.json`: Fabric, Forge, NeoForge, Quilt.
- `options.txt` — обязательные настройки игры для первой установки.

JAR не встраиваются в архив или EXE: для них нужны найденные ссылки. Ресурспаки и шейдеры тоже скачиваются по ссылкам. Конфиги, скрипты и прочие файлы перечисленных папок встраиваются; перед распространением проверьте их содержимое. Миры, скриншоты, логи, аккаунты, JVM-параметры и команды запуска не экспортируются. Произвольные патчи Prism и старые jarmods пока не поддерживаются; экспорт останавливается с сообщением.

Поиск Modrinth выполняется по SHA-512. Если остались неизвестные файлы, поиск CurseForge использует fingerprint и дополнительную проверку SHA-1. Для CurseForge нужен собственный API-ключ:

```powershell
$env:CURSEFORGE_API_KEY = "ваш-ключ"
python -m packforge
```

Ключ можно ввести в интерфейсе. Он не записывается в архив, EXE или настройки. Если автор запретил прямую загрузку, файл не найден или ключ отсутствует, утилита не выпускает неполную сборку: рядом с результатом создаётся `*.unresolved.json`. Существующий успешный экспорт при ошибке остаётся прежним. Неизвестные JAR не упаковываются «как есть».

## Установка и обновление

Закройте Minecraft и лаунчер. Для каждой сборки используйте отдельную папку.

При открытии установщик ищет уже установленную сборку по постоянному ID. Найденная копия предлагается к обновлению в прежней папке. Если копий несколько, можно выбрать нужную. Для новой установки доступны только обнаруженные лаунчеры; рекомендация выбирается в порядке **Prism → Legacy → TLauncher**.

Если лаунчеров нет, показываются кнопки официальных страниц скачивания и **«Повторить поиск»**. Для portable-версии есть **«Указать лаунчер…»**, для нестандартного расположения сборки — **«Найти сборку в папке…»**.

Автопоиск проверяет реестр Windows, стандартные каталоги программ и игр, настройки каталога экземпляров Prism, папку рядом с установщиком и сохранённые пути успешных установок. Индекс хранится в `%LOCALAPPDATA%/PrismPackForge/installations.json`; его записи проверяются по существующему журналу сборки. Поиск по папкам ограничен глубиной 6 и 10 000 каталогов на корень, не обходит библиотеки, ресурсы и миры. Полное сканирование всех дисков не выполняется. Сборки, установленные этим инструментом в произвольную папку, после успешной установки сохраняются в индексе. Старую установку вне известных каталогов нужно один раз найти кнопкой выбора папки. Наличие только папки данных или скачанного Setup EXE не считается установленным лаунчером.

**Prism Launcher:** выберите новую папку экземпляра внутри фактического каталога `instances`. По умолчанию предлагается `%APPDATA%/PrismLauncher/instances/<id>`; portable или изменённый каталог нужно указать вручную. Установщик создаёт `instance.cfg`, `mmc-pack.json` и `.minecraft`. Prism загрузит Minecraft и загрузчик при первом запуске. Для обновления укажите папку, созданную предыдущим установщиком.

**Legacy Launcher и TLauncher:** укажите игровую папку, заданную в настройках лаунчера — именно корневую папку, в которой хранится каталог `versions`. Установщик автоматически установит точную версию Minecraft, Fabric / Forge / NeoForge / Quilt из сборки, библиотеки, ресурсы, необходимую для установщика загрузчика Java и файлы сборки. Предварительно устанавливать игру или запускать её один раз не требуется. Поддерживается и Vanilla без модлоадера.

После завершения перезапустите лаунчер и выберите версию, указанную в журнале установщика, например `fabric-loader-0.16.9-1.20.1`. В Legacy должны отображаться установленные/модифицированные версии. Путь к игре в настройках лаунчера должен совпадать с выбранной папкой. Для каждой сборки задавайте отдельную игровую папку. В Legacy используйте режим **«Не использовать отдельные папки»** (Subfolders), чтобы моды читались из корня выбранной папки. Настройки аккаунтов, текущая выбранная версия и другие настройки лаунчера автоматически не меняются.

Minecraft, Java и модлоадер скачиваются во время установки с серверов Mojang/Microsoft и официальных серверов соответствующего загрузчика через `minecraft-launcher-lib`. Моды по-прежнему скачиваются только по ссылкам Modrinth/CurseForge; игровые JAR и JAR модлоадеров также не встраиваются в EXE. Загрузчик устанавливается в указанной версии, без подмены на «последнюю». Для старых версий, которые не поддерживает установщик соответствующего загрузчика, будет показана ошибка, файлы сборки не применятся.

Установщик загрузчика использует скачанную Java из папки игры, а не требует её наличия в PATH. Для запуска самой игры лаунчер использует собственные настройки Java; в Legacy можно оставить «Рекомендуемая». На время подготовки требуется дополнительное место для временной копии библиотек, ресурсов и Java. Имеющиеся файлы копируются во временную папку, проверяются/дополняются установщиком, затем новые и изменённые файлы применяются вместе с модами. Старые игровые версии и общие библиотеки автоматически не удаляются.

Для обновления запустите EXE новой версии с тем же ID и выберите прежнюю папку. Проверка обновлений через сервер пока не предусмотрена.

- Файлы сборки сначала скачиваются во временную папку и проверяются по размеру и SHA-512. Minecraft и модлоадер также подготавливаются отдельно от действующих файлов; библиотека установки проверяет контрольные суммы, предоставленные серверами. При ошибке подготовки действующие файлы не меняются.
- Журнал `.packforge/state.json` позволяет удалить устаревшие файлы предыдущей версии. Чужие моды не удаляются; вручную изменённый управляемый мод вызывает конфликт, чтобы не оставить две версии.
- При первой установке применяется `options.txt` сборки. При обновлении существующие настройки сохраняются, пока пользователь явно не включит их замену. Старые установщики без `options.txt` нужно перевыгрузить для первой установки.
- Конфиги новой версии заменяют старые с резервной копией. Изменённые пользователем устаревшие конфиги сохраняются.
- Заменённые и удалённые файлы сохраняются в `.packforge/backups/<дата-id>/` относительно выбранной папки. `index.json` сопоставляет номера резервных копий с исходными путями; автоматической кнопки восстановления пока нет.
- Если применение изменений завершается ошибкой, установщик пытается восстановить файлы из резервной копии. Отключение питания или принудительное завершение процесса не покрывается этим откатом. После аварийного завершения может остаться `.packforge.lock`; удалять его следует только после закрытия установщика.

## CLI

```powershell
python -m packforge export "C:\PrismLauncher\instances\MyPack" --id my-pack --name "Моя сборка" --version 1.0.0 --output "dist\my-pack.pack.zip" --include-options --exe "dist\my-pack-setup.exe"
python -m packforge build "dist\my-pack.pack.zip" --output "dist\my-pack-setup.exe"
python -m packforge installer "dist\my-pack.pack.zip"
python -m packforge install "dist\my-pack.pack.zip" --launcher prism --destination "C:\PrismLauncher\instances\my-pack"
python -m packforge install "dist\my-pack.pack.zip" --launcher legacy --destination "D:\Minecraft\my-pack"
python -m packforge install "dist\my-pack.pack.zip" --launcher tlauncher --destination "D:\Minecraft\my-pack"
```

Для замены настроек при обновлении в CLI добавьте `--replace-options`. При первой установке настройки сборки применяются автоматически. Экспорт всегда включает `options.txt`; старый флаг `--include-options` принимается для совместимости и больше не требуется.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют обновления, откат при ошибке применения (включая файлы игры), повреждённые загрузки, конфликты файлов, сохранение настроек, поиск CurseForge, отсутствие вложенных JAR, обработку путей и установку точных версий четырёх модлоадеров с подготовкой Java. API и установщики в модульных тестах заменены тестовыми ответами; работа с реальными лаунчерами и запуск конкретной сборки требуют отдельной проверки на её файлах.

Интеграционная проверка с реальными серверами (скачивает Mod Menu, Minecraft 1.20.1, Java и Fabric 0.16.9 для Legacy/TLauncher, создаёт тестовые файлы только в `.verification`, игру не запускает; загрузка может занимать несколько минут и более 1 ГБ на диске):

```powershell
python scripts/smoke_test.py --build
```

API и форматы: [Modrinth](https://docs.modrinth.com/api/operations/versionsfromhashes/), [CurseForge](https://docs.curseforge.com/rest-api/), [Prism data locations](https://www.prismlauncher.org/wiki/getting-started/data-location/), [minecraft-launcher-lib](https://minecraft-launcher-lib.readthedocs.io/en/stable/modules/mod_loader.html), [Legacy: установка Fabric](https://docs.llaun.ch/en/mods/fabric), [Legacy: подпапки](https://docs.llaun.ch/en/launcher/subfolders), [TLauncher: локальные версии](https://tlauncher.org/en/activate-system-skins.html), [PyInstaller](https://pyinstaller.org/en/stable/usage.html).

## Интерфейс экспорта

Сначала выберите **лаунчер** в группе «Источник». Для Prism/MultiMC показывается список их экземпляров; поля игровой папки и ручного ввода Minecraft/загрузчика скрыты. Для остальных лаунчеров показываются игровая папка, Minecraft и модлоадер. При выборе Vanilla поле версии модлоадера скрывается. Название и версия выпуска находятся в группе «Сборка», папка сохранения — в «Результат».

Кнопка **«Настройки»** открывает API-ключ CurseForge (только на текущий сеанс), постоянный ID, создание EXE, дополнительные каталоги Prism/MultiMC и режим оформления.

ID всегда читается из служебного файла **`.packforge-export.json` в исходной сборке**. При отсутствии этого файла используется ID ранее установленной утилитой сборки из `.packforge/state.json`; для новой сборки ID создаётся из имени папки и сохраняется в исходнике при экспорте. После этого перенос или переименование папки не меняют ID. У сборки с нелатинским именем при необходимости создаётся технический ID. Значение можно изменить в настройках перед экспортом — новый ID запишется в исходник. Изменение ID опубликованной сборки означает отдельную сборку для установщика.

В `%LOCALAPPDATA%/PrismPackForge/export-settings.json` есть отдельная запись `last_export`: последняя **успешная** выгрузка, её исходная папка, лаунчер, название, ID, версия, папка результата и время выгрузки. Она обновляется только после завершения экспорта и, если выбран EXE, его сборки. Выбор другой сборки, черновые изменения и ошибки этот снимок не заменяют. При запуске восстанавливается последняя успешно выгруженная сборка, если её папка доступна. Кеш содержит копию ID для истории, но не заменяет ID исходной сборки.

Переключатель **☀ / ☾** в правом верхнем углу выбирает светлую или тёмную тему. По умолчанию тема следует настройке приложений Windows, включая её изменения во время работы утилиты. После ручного переключения режим «Как в Windows» можно вернуть в настройках. Ранее сохранённый ручной выбор сохраняется.

Установщик скачивает моды по ссылкам Modrinth/CurseForge. JAR файлов внутри него нет. Конфиги, скрипты и настройки игры передаются вместе со сборкой.
